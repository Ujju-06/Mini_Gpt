# 🤖 Mini GPT

A simple GPT-style conversational AI chatbot built using **Streamlit, LangChain, and Hugging Face**.

The application provides a chat interface where users can interact with an LLM, create multiple conversations, switch between previous chats, and clear the chat history.

---

## 🚀 Features

- 💬 Chat with an AI assistant
- 🤖 Hugging Face LLM integration
- 🦜 LangChain integration
- 🗂️ Multiple chat conversations
- 📜 Chat history in the sidebar
- 🔄 Switch between previous conversations
- ➕ Create a new chat
- 🗑️ Clear all chat history
- 💾 Session-based conversation storage
- 🖥️ Simple Streamlit UI
